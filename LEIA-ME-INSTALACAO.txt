FS STUDIO MAKER ADMIN — VERSÃO INSTALÁVEL (PWA)

O QUE ESTE PACOTE FAZ
- Transforma o painel administrativo em um aplicativo instalável.
- Nome do app: FS Studio Maker Admin.
- Abre direto em admin.html.
- Funciona no Android e em computadores com Chrome/Edge.
- No iPhone/iPad, orienta a usar “Adicionar à Tela de Início”.
- NÃO substitui e NÃO altera o supabase-config.js.

COMO COLOCAR NO GITHUB
1. Extraia este ZIP.
2. Entre no repositório fs-studio-maker.
3. Envie TODOS os arquivos deste pacote para a RAIZ do repositório.
4. Quando o GitHub avisar que admin.html já existe, SUBSTITUA somente o admin.html.
5. Os demais arquivos são novos e podem ser adicionados normalmente.
6. NÃO apague nem substitua supabase-config.js.
7. Aguarde o GitHub Pages atualizar.

ARQUIVOS
- admin.html                  -> substitui o atual
- manifest-admin.webmanifest -> novo
- pwa-admin.js               -> novo
- pwa-admin.css              -> novo
- sw-admin.js                -> novo
- fs-admin-icon-192.png      -> novo
- fs-admin-icon-512.png      -> novo

COMO A FERNANDA INSTALA
Android / Chrome:
1. Abra https://fsstudiomaker.com.br/admin.html
2. Toque em “Instalar aplicativo”.
3. Confirme a instalação.
4. O ícone “FS Admin” aparecerá na tela do celular.

Windows / Chrome ou Edge:
1. Abra https://fsstudiomaker.com.br/admin.html
2. Clique em “Instalar aplicativo”.
3. Confirme.
4. O FS Studio Maker Admin aparecerá como aplicativo no computador.

iPhone / iPad:
1. Abra admin.html pelo Safari.
2. Toque em Compartilhar.
3. “Adicionar à Tela de Início”.
4. Confirme em “Adicionar”.

IMPORTANTE
O aplicativo continua usando o site e o Supabase já existentes. Ele não cria um segundo banco nem duplica os dados.
